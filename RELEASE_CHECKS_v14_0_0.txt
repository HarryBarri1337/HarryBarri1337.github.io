SkinQuest v14.0.0 release checks
================================

Before deploy
- Back up production Supabase.
- Confirm the live site is currently on the v13.1.0 database baseline.
- Run skinquest_upgrade_existing_to_v14_0_0.sql on the existing database.
- Do NOT run skinquest_full_setup_v14_0_0.sql on production.

After deploy
- Hard refresh desktop and mobile.
- Reopen installed PWA so cache v1400 replaces the previous cache.
- Sign in and confirm existing balance and reward history are unchanged.
- Confirm Earn still opens CPX and BitLabs correctly.
- Confirm reward redemption still uses the existing secure redemption flow.
- Confirm Dashboard loads quests/onboarding/activity without console errors.
- Confirm notification center loads for a signed-in user.
- Confirm reward filters and reward details work on mobile and desktop.
- Confirm an out-of-stock reward can be subscribed to for restock notification.
- Confirm cookie/analytics preferences can be changed after the initial choice.
- Confirm Admin page still requires an admin account and loads v14 KPIs.
- Confirm /offline.html is available and the PWA offline indicator works.

SQL package check
- Existing production upgrade: skinquest_upgrade_existing_to_v14_0_0.sql
- Fresh project only: skinquest_full_setup_v14_0_0.sql
- No v13 SQL or v13 README files should remain in the package root.
