SkinQuest v15.1.1 checks
========================
Code
- node --check passes for modified JavaScript files.
- HTML route, script and stylesheet references resolve in the release archive.
- The customer menu has the same six links and order on all 17 customer pages; the startup code restores the link on older cached HTML.
- The giveaway loader is started during boot, and a failed feed shows a retry state instead of staying on Loading.
- Migration includes RLS and grants for every giveaway function. Only authenticated admins can create/cancel/draw; visitors can only see public counts and authenticated users can enter.

Delivery test on a staging copy
- Ungrouped order: copy Steam message and trade URL, advance one valid step, verify other orders for that customer did not change.
- Shared delivery: select at least two unsent orders for one customer, copy the shared message, mark purchased with Steam's actual lock end, mark ready after the lock, mark trade sent, then mark completed after acceptance.
- A mixed-status shared delivery does not offer a bulk action; open one item at a time.
- A changed trade link blocks marking sent until admin review. Verify customer notification after a grouped update.

Giveaway test on staging
- Empty public page says no giveaways available right now.
- No open prizes and no recent results hides both the entry instructions and the results section; active prizes reveal the instructions.
- At desktop and mobile widths the header and giveaway panel have matching edges and a visible gap between them.
- Two admins can create multiple prize cards with custom dates; default is eight days.
- A survey credited before the creation time cannot qualify. A verified CPX or TimeWall Surveys reward after creation unlocks Enter, but does not enter automatically.
- The same later survey reward can unlock two already-open giveaways; pressing Enter on each yields one unique entry per prize.
- TimeWall Earn tasks, reversed rewards, unsigned browser claims, duplicate clicks and attempts after end do not grant an entry.
- After end, an admin can draw once and see a winner. A drawing with no currently valid entries closes without a winner. The winning admin can copy the Steam message, send/verify the offer manually, then mark delivery recorded once. Customer counts and winner contact remain appropriately scoped.
