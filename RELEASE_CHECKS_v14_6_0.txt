LIMITS OF LOCAL CHECKS
Mock API results are not proof of production behavior. Embedded PostgreSQL
uses stubbed auth and cannot reproduce every Supabase gateway/webhook setting.
Chromium checks do not verify real CPX availability, provider callbacks,
Steam responses, production CORS, email delivery or your host's Apache config.
The catalogue only contains items already imported or manually added; this
release neither completes nor speeds up the current Steam import.
